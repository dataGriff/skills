# invoicer

Generates monthly invoices for Acme customers and pushes them to the
payments provider.

## Setup

Get the `.env` file from Dave (ask in #invoicer-dev on Slack), put it in
the repo root, then:

```bash
pip install -e .
python app.py
```

## Deploying

Dave does the deploys. Ping him when something needs to go out.
